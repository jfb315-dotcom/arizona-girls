# Arizona Girls

An iPad game panel for three cousins: 31 games in six themed worlds, levels and badges, a Secret Agent HQ with a fingerprint login, and a Fun page.

Open https://jfb315-dotcom.github.io/Arizona-girls/ on the iPad and use Share > Add to Home Screen.

Names and badge photos are not stored in this repo. They are entered on the iPad (Stars & names) or loaded from a private setup link, and stay on that iPad.
