# Arizona Girls

A tablet game app for three sisters: 71 games in six themed worlds, levels, stars and photo badges, a Secret Agent HQ with a fingerprint login, and Funtime (trivia night, dice, drawing, movie picker).

Open https://jfb315-dotcom.github.io/arizona-girls/ on an iPad or Kindle Fire and add it to the Home screen.

Names, birthdays and badge photos are not stored in this repo. They reach each tablet from a private family record or a private setup link.
